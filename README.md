# rn-reorder-list

Reorderable list and grid for React Native: long-press or handle drag, auto scroll, haptics, accessibility actions, undo history

## Installation


```sh
npm install rn-reorder-list
```


## Usage


```js
import { multiply } from 'rn-reorder-list';

// ...

const result = multiply(3, 7);
```
